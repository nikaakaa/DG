# 使用容器类型

容器是最常用的类型。Luban支持丰富的容器数据格式，可按需选择类型和填写方式。

## 容器定义

目前支持4种基础容器类型：

| 容器类型 | 描述 | 示例 |
| --- | --- | --- |
| array | 数组类型，生成代码对应原生数组，如C#中的`xxx[]` | `array,int`、`array,Item` |
| list | 列表类型，生成代码对应List容器，如C#中的`List<xx>` | `list,string`、`list,Color` |
| set | 集合类型，元素唯一，生成代码对应Set容器，如C#中的`HashSet<xx>` | `set,int`、`set,Color` |
| map | 字典类型，键唯一，生成代码对应Map类型，如C#中的`Dictionary<xx,yy>` | `map,int,int`、`map,string,Item` |

## 填写array、list、set数据

常见填法：
1. **占多个单元格**：字段名占多列（合并单元格或用`[{字段名}`/`{字段名}]`标记），每个单元格一个元素
2. **占一个单元格**：用`sep=x`指定分割符（如`sep=,`），元素用分割符分隔

## 填写map数据

map包含key和value，可：
- 在一个单元格内填写，用双分隔符区分键值对和键/值
- 占多个单元格，每个单元格一个键值对
- 多行填写，字段名前加`*`表示多行数据
