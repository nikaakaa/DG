# excel格式（高级）

## 限定列格式
通过标题行及多级标题头，可以精确限定某个数据在某些列范围内。

限定列格式下，多态bean类型需要用 $type 列来指定具体类型名，可空bean类型也需要用$type列来指示是有效bean还是空bean。

如果最低层的限定列的类型为容器或者bean，读取子数据的格式为**流式格式**，即按顺序读入每个子数据。

### flags enum 支持列限定模式
用枚举项作为列名，最终值为所有非0或空的枚举项的**或值**。

### 多态bean支持 $type与$value分别配置
即用$type列为限定类型，用$value列来限定bean的实际字段，并且$value中以流式填写bean的所有字段。

### map的列限定格式
有两种填法：
- 多行填法。$key子列对应key字段，剩余列对应value的子字段
- 非多行填法。可以将key作为子字段名，如果对应的单元不为空，则对应key-value的键值对存在

## 多级标题头
有时候某些字段是复合结构，按顺序填写时容易写错。多级标题可以用于限定bean或容器的子字段，提高了可读性，避免流式格式的意外错误。

通过在某个`##var`行下新增一行`##var`，为添加子字段名，则可以为子字段设置标题头。可以有任意级别的子标题头。

## 多行结构列表
将字段名标记为`*<name>`即可表达要将这个数据多行读入。支持任意层次的多行结构列表。

对于`array,bean`、`list,bean`这样的结构容器类型，还可以配合限定列格式，限定元素中每个子字段的列。

## 常量别名
策划填写数据的时候，有时候希望用一个字符串来代表某个整数以方便阅读。

在xml schema文件中定义`constalias`常量别名。

```xml
<module name="test">
  <constalias name="ITEM0" value="1001"/>
  <constalias name="ITEM1" value="1002"/>
</module>
```

常量别名仅能用于`byte、short、int、long、float、double`类型的数据，并且仅在excel族和lite类型源数据中生效。常量别名没有命名空间的概念，**不受module名影响**。

## 紧凑格式
如果某个数据是非原子数据（如bean或容器），并且它被限定到某些单元格列范围或者是sep分割的数据的一部分，则它的解析方式为**紧凑格式**。详细见Excel紧凑格式文档。

## 数据标签过滤
开发期经常会有仅供开发使用的配置。可以通过给记录加上tag，再配合命令行参数 --excludeTag实现。`##`是一个特殊的tag，表示这个数据被永久注释，任何情况下都不会被导出。
